Deplexo publishes its CLI, documentation, and starter apps on GitHub. Use each repository's issues and pull requests to report problems or contribute changes.

| Project | What it contains | Where to start |
| --- | --- | --- |
| [Deplexo/cli](https://github.com/Deplexo/cli) | The `deplexo` command for signing in, managing apps, deploying from Git, and reading logs. Licensed under Apache-2.0. | [CLI guide](/guides/cli/) and [installation site](https://cli.deplexo.com/) |
| [Deplexo/docs](https://github.com/Deplexo/docs) | The source for this documentation site. Licensed under MIT. | [Repository README](https://github.com/Deplexo/docs#readme) |
| [Deplexo/examples](https://github.com/Deplexo/examples) | Starter websites, APIs, and bots with source, build files, and setup instructions. | [Choose and export a template](/getting-started/templates/) |

Check the license and notices in each repository before reusing its code. The template exporter includes the starter's license in your copy.

## Build tools for Deplexo

The CLI uses the public REST API. You can use the same API from scripts or other clients to manage your apps. The [user API guide](/reference/user-api/) covers authentication, permissions, deployment requests, and logs.

## Contribute

For a docs correction, use the page's edit link or open a pull request in [Deplexo/docs](https://github.com/Deplexo/docs). For a CLI bug, include the command, CLI version, operating system, and the error you received. Remove credentials and private data from logs before posting them.

Use [Deplexo support](https://deplexo.com/support) for account or application issues that need private information.
